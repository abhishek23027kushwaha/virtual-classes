## 📌 Overview

> **Virtual Classes** is a modern, full-stack **EdTech & Learning Management System (LMS)** designed to bridge the gap between ambitious learners and passionate educators.

Built using the **MERN** stack (MongoDB, Express, React, Node.js), Virtual Classes empowers educators to create, structure, price, and publish multi-lecture video courses, while providing students with an intuitive learning experience complete with **AI-powered search (Gemini 2.5 Flash)**, **Razorpay checkout**, **free video previews**, and **interactive course reviews**.

## 🔄 How It Works

### 👤 Student Learning & Enrollment Journey

```mermaid
flowchart LR
    A([Visitor]) --> B[Sign Up / Login]
    B --> C[Browse Courses]
    C -->|Natural Language| D[Gemini AI Search]
    C --> E[View Course Details]
    E --> F{Preview Free Lecture?}
    F -->|Yes| G[Watch Free Demo]
    F -->|No| H[Razorpay Checkout]
    G --> H
    H --> I[HMAC Verified on Backend]
    I --> J[Course Enrolled in Dashboard]
    J --> K[Watch Full Curriculum & Leave Review]
```

### 💳 Razorpay Payment & Server Verification Flow

```mermaid
sequenceDiagram
    participant S as Student (Browser)
    participant F as React Frontend
    participant B as Express API
    participant R as Razorpay Gateway
    participant DB as MongoDB

    S->>F: Click "Enroll Now"
    F->>B: POST /api/payment/order (courseId)
    B->>DB: Check course & price
    B->>R: orders.create({ amount, currency: INR })
    R-->>B: Order Details (order_id)
    B-->>F: Return order_id & course info
    F->>S: Open Razorpay Checkout Modal
    S->>R: Complete Payment (UPI / Card / NetBanking)
    R-->>F: razorpay_payment_id, order_id, signature
    F->>B: POST /api/payment/verify
    B->>B: Compute HMAC-SHA256 signature
    alt Signature Matches
        B->>DB: Add courseId to user's enrolledCourses
        B->>DB: Add userId to course's enrolledStudents
        B-->>F: 200 OK (Payment Verified)
        F->>S: Redirect to Enrolled Courses
    else Signature Invalid
        B-->>F: 400 Bad Request (Fraud detected)
    end
```

## 🚀 Getting Started

### ✅ Prerequisites
* **Node.js 18+** installed on your system
* **MongoDB** (Local instance or free [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) URI)
* Free **Cloudinary** account (for media storage)
* Free **Razorpay** test keys (for checkout testing)
* Free **Google Gemini API Key** (from [Google AI Studio](https://aistudio.google.com/))

---

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/abhishek23027kushwaha/virtual-classes.git
cd virtual-classes
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file in the `backend/` directory:
```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key

# Cloudinary CDN credentials
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret

# Email service for OTP reset
EMAIL=your_email@gmail.com
EMAIL_PASS=your_email_app_password

# Razorpay credentials
RAZORPAY_KEY_ID=your_razorpay_key_id
RAZORPAY_SECRET=your_razorpay_secret_key

# Google Gemini API
GEMINI_API_KEY=your_gemini_api_key
```

**Seed 20 comprehensive courses, lectures & reviews:**
```bash
npm run seed
```

Start the backend development server:
```bash
npm run dev
```
> The API will be running at `http://localhost:8000`.

---

### 3️⃣ Frontend Setup

In a new terminal window:
```bash
cd frontend
npm install
```

Create a `.env` file in the `frontend/` directory:
```env
VITE_SERVER_URL=http://localhost:8000
```

Start the frontend development server:
```bash
npm run dev
```
> The web application will launch at `http://localhost:5173`.
